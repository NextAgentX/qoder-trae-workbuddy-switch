# v2026.11.161428

## 长上下文不再被整段丢弃

- 网关的历史输入裁剪上限从 256 KiB 提升到 1.5 MiB（约 38 万 token），够覆盖主流模型 200k+ 的上下文窗口，长对话与多步工具调用不再因为超限被静默丢掉整组历史。
- 新增环境变量 `BUDDY_SWITCH_MAX_INPUT_BYTES` 可自定义预算；设为 `0` 表示完全不裁剪。
- Responses 会话缓存的条目上限同步提到 2 MiB 并与输入预算联动，避免大历史被以「条目过大」为由拒收。

## 会话身份与失败日志

- 会话身份在历史裁剪**之前**解析：裁掉首轮提问后，同一段对话不会再被当成另一个会话。
- 内容指纹升级为 v2：取首轮之前的全部 system / developer 指令加首条用户消息，不同项目的会话互相隔离。
- 发流前的 HTTP 与本地失败会写入 `error` 字段：优先保留上游原因，未触达上游时用本地文案；脱敏先于截断，长文本按 Unicode 字符限长 4096。
- 中国区出站在发送边界再次规范化 `developer` 消息为 `system`，补齐此前漏掉的调用方。

## 缓存命中统计

- 聚合用量时，只有后一帧缺少缓存字段才继承前一帧的值；后一帧明确上报 0 时以 0 为准，不再把未命中误记成命中。

## 选号与限流

- Qoder 因模型冷却而无候选账号时，返回 429 并带 `Retry-After`，不再提示导入账号。

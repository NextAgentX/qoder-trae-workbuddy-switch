## Trae 卡片不再显示「1970-01-22 · 即将过期」（#181）

- JWT 的 `exp` 是**秒**，此前直接当毫秒格式化 ⇒ 明明凭据是好的，卡片却显示 1970 年并标「即将过期」。现在视图出口统一换算成毫秒（与 WorkBuddy / Qoder 的时间字段同口径）。
- 同一个单位错误还有一处：聚合页的「待处理」判定把秒级值跟当前毫秒比较 ⇒ **Trae 账号一直被当成已过期**排在前面。修了单位，两处一起好。
- 内部仍是秒：冷却记录匹配、登录态快照校验、账号池的凭据比对都与上游原始 `exp` 直接对照，不换算。

## Qoder 令牌刷新遇到 415 现在会自动换一种编码（#182）

- 现象：`drt-` 账号刷新稳定回 `415 Unsupported Media Type`，自动续期完全不可用。
- 现在先按 JSON 发（与原来一致），**只有 415** 才改发 `application/x-www-form-urlencoded`，成功即记住；401 / 403 / 400 不重试（那是凭据或参数问题，重试只是多打一次上游）。
- 两种编码都被拒时，错误里会同时带两次上游响应的原文 —— 下一次反馈就能直接定位，不用再问「你发的是哪种」。

## 三平台风控设置

- WorkBuddy、Trae、Qoder 的 API 服务页均可按平台和区域配置请求速率、账号并发、全局并发、账号间隔、临时故障重试次数和限流冷却时间。
- 认证拒绝和限流状态会按平台、区域、账号保存；后续请求会跳过暂停或冷却账号，并提供人工恢复入口。
- 补齐三平台网关及常用后台账号请求的风控准入。遇到认证拒绝、额度不足、限流或结果不确定的请求时，不自动换号重放。
- 账号继续使用平台已有身份；账号请求共享平台网关出口。风控设置用于约束本地请求行为，不保证平台账号处置结果。

|:--|:--|

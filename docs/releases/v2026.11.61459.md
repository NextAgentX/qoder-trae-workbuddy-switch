## 🐛 问题修复

- 修复健康账号被误标「需重新登录」：刷新遇到断网（code=-1）或 HTTP 5xx 时不再当成凭据被拒，只把原因挂在返回值、不写进账号库；业务拒绝码（12153 invalid_grant / 401 / 403）仍落标记（issue #171）。
- 修复徽章滞留：后台清除标记后，60 秒轮询同时重拉国内版与国际版账号列表，≤60s 内徽章自动消失，不必重开窗口（issue #171）。
- 手动「刷新 Token」遇暂时性失败改为警告提示（含原因），不再冒充成功、也不误报需重新登录。
- 保活结果新增 `transient` 一态；已带历史误标的账号本轮暂时性失败也优先报 `transient`。
- 聚合页「需处理」口径与三平台卡片对齐：Qoder 凭据「认不出」也进待处理；三平台语义收口到单一装配点。
- 账号「需重新登录」标记不再每晚重复写盘：保活对已带同一条原因的死账号只记 `skipped`。

## 已知限制

- 刷新只能换取新的 access token，无法延长上游签发的有效期；refresh token 链条一旦断开（加密信封解不开、上游会话被清理返回 12153、11140 硬禁用），本地定时保活救不回来，仍需重新登录或重新导入凭据。
- Trae 从本机抓取 / 备份导入的 JWT 没有 refresh token，也不带设备私钥，不支持自动续期，只能重新获取 JWT。
- 当前 GitHub Actions 的 macOS runner 被平台侧取消 ⇒ 本版 Release **不含 macOS 资产**（Windows / Linux 产物齐全）；恢复需平台侧修复 runner 配额或可用性。
- macOS 安装包仍未签名与公证：从网络下载后如提示「已损坏」，执行 `xattr -dr com.apple.quarantine /Applications/BuddySwitch.app`。
- 「积分自动刷新」仍默认关闭：需要时在「设置 · 通用 · 积分自动刷新」开启；Token 保活默认开启，与积分刷新是两个开关。

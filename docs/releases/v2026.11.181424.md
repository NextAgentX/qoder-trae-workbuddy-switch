## 会话关联与工作台

- 可把 WorkBuddy CN / Global、VS Code 与 CodeBuddy IDE 中对应的会话关联成组，在会话工作台查看关联、详情与来源关系。
- 关联同步先生成预览，展示待应用内容与归档变更；确认后再执行，并通过操作日志支持失败恢复。
- 支持为会话组添加、解除关联、批量同步和统一会话；解除关联或删除分组不会改写会话正文。
- 旧版 WorkBuddy 关联记录和 IDE 扩展复制记录会按来源迁移，保留已有关系并避免重复导入。

## 切换账号时管理会话

- 切换账号前可预览并选择要同步的关联会话，支持 WorkBuddy、VS Code 扩展和 CodeBuddy IDE 的会话复制流程。
- WorkBuddy 支持跨区域关联与同步，提供归档策略、写入前快照和恢复记录。
- 修复前端页面热更新后动态模块文件已更换时无法加载会话页面的问题。

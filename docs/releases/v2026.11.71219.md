## Trae 工具调用终于能用了（#172）

- `trae-cn` 此前只能当纯对话用：上游把一次工具调用拆成两帧发（先函数名、后参数），网关每帧各自转换，一次调用就落成「有名无参」+「无名有参」两条残缺记录，客户端两条都判成非法。
- 现在按帧累加成一条完整调用，`finish_reason` 也正确报 `tool_calls` —— 此前固定 `stop`，Anthropic 侧因此映射成 `end_turn`，客户端会直接丢弃工具结果。
- `/v1/chat/completions` 与 `/v1/messages` 两条链路都修好了。

## Trae 没有客户端也能拿到模型清单（#173 · 需要手动触发）

- Docker / headless 部署里没有客户端，模型清单此前永远退化成内置兜底表。现在模型卡空态多了一个「从上游拉取清单」按钮：用账号池里的凭据直连 Trae IDE 接口抓一次，结果缓存 6 小时；客户端缓存在时仍以客户端为准。
- 这是一次**带账号凭据的上游请求**，所以只在客户端缓存读不到时才出现，且只在你点击时发生 —— 不做自动刷新、不做轮询。
- 只支持国内版（国际版没有实测证据，会如实说明而不是猜一个域名）。

## Qoder 卡片能看「最近 N 积分 · X 天后过期」（#166）

- 与 WorkBuddy 卡同一口径，两枚徽章互斥：橙色 = 14 天内临期（警告），中性 = 最近一批（回答「我先用哪个号」）；悬停看逐批明细。
- 未登录网页端时整条不渲染 —— 不给一个猜出来的天数。

## CodeBuddy IDE 切换账号后给「复制会话」入口（#86 前半）

- 切换成功的提示里多了一个「复制会话」按钮：来源是切换前的账号、目标已选中刚切到的账号，点开就是原来的会话抽屉。
- **不会自动复制** —— 写数据必须由你点。
- 记忆合并（`~/.codebuddy/memery/`）还没做：本机实测该目录不存在，需要样本才能确定结构；按错格式合并会毁掉目标账号的记忆。

## Trae「快照不存在」的提示能自证了（#152）

- 以前只写「请先保存该账号的登录态」，而你明明存过。现在补三件事：保存拷的是**客户端此刻**的登录态（要先把该账号登录进客户端）、**查过哪些池**、**客户端此刻登录的是谁**。
- 哪里都没有时依然不会编一个路径出来。

# v2026.11.141713

## 网关会话隔离

- Responses 请求的状态链在「产品线 + 区域 + API Key」之外，再按客户端提供的会话身份隔离：Codex、Claude Code 等各自携带的会话 ID 会被换算成不可逆指纹后写进状态键，原始 ID 不落盘、不进日志。
- 续接请求临时缺少会话身份时，只有该 previous_response_id 在当前范围内唯一才会继承原身份，避免不同对话串到同一条上下文上。
- 会话状态容量与空闲过期策略统一：命中即续期，容量压力下按最近访问时间淘汰，输入历史预算提高到 256 KiB。

## 缓存命中与选号

- 请求日志区分「上游没有上报缓存字段」与「明确上报未命中」，命中率统计不再把缺失数据当成 0。
- Chat Completions 客户端未携带会话头时，改用 system 指令与首条用户消息的内容指纹绑定账号，减少同一段对话反复换号导致的缓存冷启动。

## 账号终态处置

- 认证拒绝、限流、排队、余额耗尽不再自动换号重试，而是原样返回上游状态码；被拒账号进入冷却，其它账号不受牵连。

## 下载与安装

- 发布包继续区分桌面安装包与命令行程序；下载时按操作系统和处理器架构选择安装包。

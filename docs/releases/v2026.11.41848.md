## 🚀 新功能

- 密钥明文改为**可选保存**：创建后弹面板二选一 —— 「保存到本软件」则写入本机台账，此后列表里点眼睛可随时查看 / 复制；「自行保存」（或直接关掉面板）则与旧版一致，只有掩码、明文只在你眼前出现过一次。四条产品线（WorkBuddy / Trae / Qoder / 统一网关）口径一致。
- 创建密钥时支持填入**已有的自定义密钥**（沿用别的平台或历史密钥）：留空仍按各产品线前缀自动生成；填写则原样使用（只去首尾空格，不补前缀、不改大小写）。同一产品线内重复的密钥会被拒绝创建，提示里点名占用者；若占用者已被吊销，会直接提示「点恢复可继续使用」。
- 密钥列表的掩码列统一成「前缀 + 尾部 4 位」，并带一枚眼睛：有真实明文时才能点开，旧密钥不出现「点了没反应的死按钮」。

## 🛠 其他

- 同一把密钥不再能在一份台账里落两条记录：查重覆盖全部记录（含已吊销），否则「吊销一条、另一条照用」会让吊销变成一句空话。
- 明文落盘只有一个入口，且写入前会校验它与记录里的 `sha256` 一致 —— 传错值、串了另一把都会被拒绝，不会存下一条「眼睛显示的值根本不能用」的密钥。
- 自定义密钥重复时，WebUI（HTTP 400）与桌面端（`ok:false` + 原因）错误口径对齐，前端在创建对话框里直接显示原因、不关窗，改完可重试。
- 新增门禁：创建不得无条件落盘明文、四张表必须共用同一套掩码 / 眼睛构件、「自行保存」不得被接上保存动作、`data-act` 同文件内唯一。
- 版本号统一为 2026.11.41848（全部载体校验通过）。

## 已知限制

- 自定义密钥**没有长度校验**：过短的密钥（少于 4 个字符）在列表里的掩码就等于它本身。
- 列表接口会下发已保存的明文，而管理面（本机回环地址）无认证：本机上的其它进程同样能读到 —— 与直接读台账文件同级，不额外扩大面，但请勿把管理面端口暴露到公网。
- macOS 安装包仍未签名与公证：从网络下载后如提示「已损坏」，执行 `xattr -dr com.apple.quarantine /Applications/BuddySwitch.app`。
- 「自动刷新」仍默认关闭：需要时在「设置 · 通用 · 积分自动刷新」开启；各页面都保留了手动刷新入口。

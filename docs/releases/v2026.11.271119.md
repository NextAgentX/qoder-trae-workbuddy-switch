## 豆包 / Loomy / 商汤小浣熊：三个新平台

- 顶栏的作用域菜单现在有 **9 个作用域**：原来的 WorkBuddy、Trae、Qoder 三平台六个区域，加上豆包、Loomy、商汤小浣熊三个独立平台。
- 三个新平台各有**五个自己的入口** —— 概览、账号、用量、网关、设置，和 WorkBuddy 同级，不是挂在某个作用域下的附属功能。切过去之后侧栏、页头和卡片都跟着换。
- 每个平台有自己的**余额查询**：在「账号」里粘贴消费端凭据，就能读到账号列表和剩余额度；余额按账号汇总显示在概览上。
- 每个平台有**自己的本地网关**：豆包 `57896`、Loomy `57897`、小浣熊 `57898`。都是只绑回环、各自一份 API Key，跟 WorkBuddy / Trae / Qoder 的网关完全隔离。支持 OpenAI Chat Completions、Anthropic Messages 和 OpenAI Responses 三种协议，以及 `GET /v1/usage` 请求记录。
- 豆包网关额外支持图片输入（本地 base64 或公网 HTTPS）与图片、视频、音乐生成接口。

## 账号页与网关页对齐 WorkBuddy

- 三个平台的「添加账号」改成和 WorkBuddy 同款抽屉：左侧安装方式、右侧表单，底部「更多操作」里放自动刷新、余额不足提醒和手动刷新。
- 网关页换成统一的 `GatewayShell` 骨架，补齐端口、账号池、模型数、失败原因和请求记录分区。和 WorkBuddy 网关页逐块对得上。

## 平台图标

- 三个平台换成**官方图标**（豆包、讯飞 Loomy、商汤小浣熊各取自官网 favicon / apple-touch-icon），和 WorkBuddy / Trae / Qoder 的图标用同一套画布参数与圆角。
- 顶栏「聚合」入口换成一个四宫格标记 —— 它横跨三个平台，用任何单一平台图标都会读起来像「当前在 WorkBuddy」。

## ⚠️ 三个新平台尚未详细验证

- 这三家平台的接入是**照着协议和页面结构写的**，还没有用真实账号逐个跑通。余额查询、模型列表、流式转换、图片 / 视频 / 音频生成的返回口径，都可能和真实上游不一致。
- 如果你是第一个用的人，碰到读不到余额、模型列表为空、流式卡住或返回格式不对，都属于**预期内的未验证状态**，不是「已经测过还坏了」。欢迎带着日志提 issue。
- 原有的 WorkBuddy / Trae / Qoder 三条产品线不受影响，可以照常用。

## 顺带

- 升级后外部平台入口**自动出现**在作用域菜单里，不需要手动开启（旧版本的可见性配置会做一次迁移）。
- 聚合页、备份、跨作用域切换、跨平台统计一律只用原来六个作用域 —— 外部平台没有客户端账号池，混进去会让聚合数字和实际账号数对不上。
- 「切换账号」的跨作用域选项不再列出外部平台（那里没有可切换的客户端账号，列出来每一行都会套错名字）。

## CodeBuddy IDE 复制会话时可以一起搬长期记忆（#86）

- 会话抽屉里多了一个「同时合并长期记忆」勾选（默认勾选）：把源账号的 CodeBuddy IDE 记忆（`~/.codebuddy/memery/`）合并给目标账号，与会话复制在同一个动作里完成。
- **加法**：逐行去重，目标账号原有的记忆一个字都不会被动；改写前自动备份到 `backups/memory/{时间戳}/`。
- 会话一条都没勾也能只合并记忆；记忆合并失败**不影响**会话复制的结果（单独一条警告，带后端原话）。
- 只想搬记忆不想搬会话时，把会话全取消勾选、保留记忆勾选即可。

## 一条需要说明的边界

- IDE 记忆文件的内部结构目前**没有样本**（本机没装登录过的 IDE）。因此工具按「认清才写」处理：纯 markdown 走逐行合并；JSON 信封只替换识别到的正文键、其余键逐字保留；**认不出来就拒绝并列出实际键名**，绝不猜着写。
- 版本记录文件 `user-memery-state.json` 一律不动 —— 它的语义未知，乱改等于告诉客户端「记忆是脏的」。
- 如果你点了合并后看到「结构认不出（现有键：…）」，把那句贴到 issue #86，加一个键名就能支持，不用改架构。

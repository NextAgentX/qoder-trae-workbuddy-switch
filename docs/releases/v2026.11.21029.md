## 🐛 问题修复

- 切换账号后目标账号不再「暂无任务」：全新账号（`sessions` 表里一行都没有）复制会话时，会补写会话索引行，并在写完后回读确认归属；失败会明确报错，而不是提示「重启客户端等它重建索引」——客户端从来不会重建索引。
- 修复「副本的副本」雪崩：复制账本现在记录**会话血缘**（这个会话最初来自哪个账号的哪个会话）。把上一次复制出的副本再复制给别的账号时会被识别并跳过，不再每切一次账号就让聊天记录文件翻一倍。
- 记忆迁移不再串号：账号记忆文件是带内嵌 JSON 的格式，此前按纯文本拼接，会把**源账号的 uid** 写进目标账号的文件。现在解析后合并正文，并强制把 uid 改写成目标账号；重复迁移保持幂等。
- Claude Code / Codex 经代理接入时粘性生效：会话粘性此前只认请求体里的 `metadata.conversation_id`，现在也认 `x-claude-code-session-id`、`x-session-id`、`x-conversation-id` 请求头与 Responses 协议的 `session_id` 字段 —— 同一会话固定落在同一个账号上，上游前缀缓存能命中。
- Trae 积分包明细不再全是「未命名包」：包名改从上游的包顶层字段读取（此前取错了层级，命中率恒为 0）。
- Trae 积分包明细不再列出已经用完的包，且按到期时间排序，与徽章上「N 天内到期」的金额口径一致。
- 聚合账号面板的积分包进度条宽度修正：比例此前少乘 100，实际只剩正确宽度的百分之一。
- 聚合账号面板的抽屉现在能显示 Trae 的逐包明细（此前区块恒为空，因为账号快照里不含逐包数据）。

## 🛠 其他

- 版本号统一为 2026.11.21029（全部载体校验通过）。
- 「积分 X/Y」的 Y 不再把已过期的包算进去；该指标行改为纯文本，逐包明细挂在临期徽章上。

## 已知限制

- 复制账本升级为带血缘的格式，**旧条目仍可读取**（不会被当成「没复制过」而全量重来），但升级前生成的副本没有血缘记录，无法被自动识别为副本。
- 会话索引行的 `created_at` / `updated_at` 仍取复制时刻，尚未回填源会话的真实首尾时间。

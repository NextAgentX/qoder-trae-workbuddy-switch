## 工作台与请求风控

- 工作台风控改为在「设置 → 通用」统一配置，默认关闭；关闭时恢复原有请求行为。开启后可统一限制三平台的请求速率、账号并发、平台总并发、账号请求间隔和限流冷却。
- 认证拒绝、限流与冷却状态仍按平台、区域和账号独立保存；账号被暂停时不会被选号器继续命中，避免把已有风险扩散到其它账号。
- 补齐 WorkBuddy、Trae、Qoder 的网关与后台请求接入。遇到认证拒绝、额度不足、限流或结果不确定的 POST 时停止自动换号与重放；冷却和暂停状态跨重启保留。
- 账号继续使用平台原有身份与共享出口。风控只约束本软件发出的请求，不承诺平台的账号处置结果。

## 记忆与会话

- 修复切换账号时未迁移 buddy 智能体个人工作区 `MEMORY.md` 的问题。迁移会合并双方已有记忆、按行去重，并在改写前保留备份；源文件缺失或只是空壳模板时明确标记跳过，不再显示「成功迁移 0 行」。

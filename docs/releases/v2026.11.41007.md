## 🐛 问题修复

- 统一网关的「接入地址」补上 `/v1`（#165）：此前概览行显示并复制的是根地址，填进任何 OpenAI 系客户端都会打到 `/chat/completions` 而 404；而同一屏的「接入说明」写的又是带 `/v1` 的串 —— 两个口径只能靠试。
- 监听地址切到「局域网 `0.0.0.0`」后，接入地址不再给出不能当目标用的串：展示与复制一律归一到 `127.0.0.1`，与 Trae / Qoder 两页一致。
- 配置还没加载完时不再显示 `http://127.0.0.1:/v1` 这种照抄必失败的地址（改为「—」并禁用复制按钮）。
- 接入说明里的两个 curl 样例改用根地址拼接：改完上一行后若不同步，会得到 `/v1/v1/chat/completions`。
- Trae 的「临期」不再有两个答案（#144）：积分页的到期分桶与账号抽屉的积分指标块此前在前端写死 7 天，而后端窗口是 14 天 —— 一个 10 天后到期的包会在卡片上说临期、点开抽屉却不说。

## 🛠 其他

- 网关对外地址收成一个派生入口：根地址与 OpenAI 基址分两个函数，`0.0.0.0` 只在一处归一，四个网关页不再各自拼串。
- 新增门禁锁住这条口径（归一回环、`/v1` 只加一次、端口缺失不伪造、`src/**` 不许手拼地址），以及「临期窗口只剩后端标记与镜像常量两档」。
- 集成文档里「界面 Base URL 缺 `/v1`」这条已知偏差已收口，改为口径约定 + 门禁说明。
- 版本号统一为 2026.11.41007（全部载体校验通过）。

## 🚀 新功能

- 会话导出 / 导入（#87）：把某个客户端的会话打包带走，换机 / 换区不用重新积累；导入前有确认对话框，重复项按内容判重，不会把目标侧已有的记录再叠一遍。
- 设置页每项现在标明是「全局」还是「仅本作用域」（#122）：以前只有老用户凭记忆，改错地方要回退。
- 聚合页的 Qoder 抽屉补了「读取逐包明细 / 退出网页登录」引导：此前逐包为空时只有一片空白，分不清「没登录」与「真的没有包」，也没有任何按钮。

## 🐛 问题修复

- 资源包的到期时间不再显示成 1970：Trae 的到期时刻是 Unix **秒**，聚合页却按毫秒渲染，于是「2026-11-21」显示为「1970-01-22」。现在量纲在入口统一为毫秒，只在一处换算。
- 资源包进度条不再只有 1/100 宽（`ratio` 漏乘 100）；已用完的包不再列出；列表按到期时间排序、已过期整体垫底 —— 三个渠道页与聚合页同一口径。
- 「临期」不再有两个答案：卡片按后端的 14 天窗口判定，抽屉却写死 7 天，于是 10 天后到期的包「卡片说临期、点开抽屉不说」。现在都读后端标记。
- Qoder 账号页的「刷新积分」现在真的会刷新积分：此前只换令牌，卡片上的额度数字不会变，却弹一个「已刷新积分」的成功提示。
- Qoder 积分页正常态补了刷新按钮（此前只有加载失败时才出现，一旦自动刷新关掉就既不会更新也没法手动更新）。
- 「已用 X」这句话在四个入口统一（聚合页与 Qoder 此前只显示裸数字，看不出那个数是「已用」还是「剩余」）。

## ⚡ 行为调整（请留意）

- **「向官方查询余额 / 用量」的自动刷新改为默认关闭**，需要时在「设置 · 通用 · 积分自动刷新」里开启。它每次都是真的上游请求，不该替用户决定；关掉后打开页面或点刷新仍会更新。只读本地快照的视图（Trae 积分 / 账号）不受影响，仍会自动跟随后台同步。
- 自动刷新的节拍不再固定：加了 ±20% 的间隔抖动，文案相应改成「约每 N 分钟」，避免所有实例在同一分钟集中发请求。

## 🛠 其他

- 版本号统一为 2026.11.31506（全部载体校验通过）。

## 已知限制

- macOS 安装包仍未签名与公证：从网络下载后如提示「已损坏」，执行 `xattr -dr com.apple.quarantine /Applications/BuddySwitch.app`。
- Anthropic 入口（`/v1/messages`）默认仍不转发图片，需要 `BUDDY_SWITCH_ANTHROPIC_FORWARD_IMAGES=1` 才透传；OpenAI 兼容入口（`/v1/chat/completions`）本来就透传。
- 「自动刷新」默认关闭后，余额不会自己动：每个受影响的页面都保留了手动刷新入口（WB 统计页「刷新积分」/ Qoder 积分页「重新查询」/ 账号卡「更多 → 刷新积分」）。

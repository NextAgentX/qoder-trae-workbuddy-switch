## 0. 方法与口径

### 0.1 状态图例

| 标记 | 含义 |
|:---|:---|
| ✅ **已实现** | 真实代码里有等价行为，并给出 `文件:行` 证据 |
| ⚠️ **部分实现** | 只做到一半，或形态差异会导致行为不完整 |
| ❌ **未实现** | 真实代码里找不到对应实现 |
| ⬜ **原型特有 / 不适用** | 断言检查的是**原型演示数据或原型专属 DOM/CSS**，真实代码**不该照搬**（详见第 4 节） |

### 0.2 ⚠️ 原型编号 ≠ PLAN 期次（必须读）

`verify-behaviors.cjs` 里的 `P0-*` / `P1-*` / `B*` / `F*` **不是** `PLAN.md` 的 P0–P12 期次——
它们是**原型自身的迭代轮次**（PLAN §8 的配套 demo 修复批次）。例如原型 `P0-1`（merge 真实聚合）与
`PLAN` 的 P0（冻结词汇表 + 注册表骨架）**毫无关系**。

本文件按 **PLAN §5 的分期（P0–P12）** 归属，并说明每条行为的映射依据（见每张表的「映射依据」列）。
对无法归入某一期的既有能力，单列「既有能力（非新期次）」。

### 0.3 统计口径

- 断言总数：**112**（与 `verify-behaviors.cjs` 的 `check(...)` 计数一致）。
- 归属判定依据：先读**断言体**（不看名字），再看真实代码的等价行为。
- 「等价行为」判据：**用户可感知的结果一致**即可，不要求 DOM 结构一致（原型用 `data-act`，真实用 shadcn/React 事件）。

## 4. ★ 不能 / 不该照搬的行为（原型特有）

> 原型是**浏览器里的静态 HTML 演示**（jsdom 驱动）。以下行为在真实桌面应用里需要**完全不同的实现**，
> 或**本就不该存在**。**不要为了「让断言变绿」而在真实代码里造出对应结构。**

### 4.1 必须换实现方式的（能力存在，但实现范式不同）

| 原型行为 | 为什么不能照搬 | 真实实现需要什么 |
|:---|:---|:---|
| **桌面悬浮窗**（§3.16 / P9） | 原型是主页面内的一个 `.companion` DOM 浮层；真实需求是**独立窗口** | Tauri `WebviewWindow`（独立进程/窗口）+ 托盘开关 + 只读状态订阅；**独立窗口的键盘可达性单独验证**；关闭即回退 |
| **请求代理**（§3.19 / P12） | 原型是静态演示表；真实要动**系统证书与网络栈** | 自签 CA 安装 + TLS 中间人 + 系统/客户端代理配置 + 白名单域过滤 + 一键还原；**PLAN 明确 P12a spike 是 go/no-go**，spike 失败整个 P12 作废（无兜底） |
| **权限自检「重试切换」按钮**（F1） | 原型是 `#perm-retry` 定数 3 轮×2000ms 的死按钮形态 | 真实是 `switch-account-dialog.tsx` 的 **error 驱动轮询**（`permission.denied` 结构化错误码触发），形态应保持现状，不必改成按钮两态 |
| **会话迁移三步向导**（B1） | 原型是独立步骤页（`wiz-next`/`wiz-cross`） | 真实是**单页对话框**（来源版本 + 会话树 + 切换）。是否重构成向导需产品决策（见第 5 节） |

### 4.2 不该在真实代码里存在的（原型演示数据 / 专属 DOM）

| 原型行为 | 为什么不适用 |
|:---|:---|
| `P0-2 各作用域 days 末值 = 账号 todayTokens 合计` | 断言的是原型**演示数据对象** `USAGE/SCOPES`。真实数据来自后端 API，**不存在这些对象**——在真实代码里造一份只为满足断言是**假验证** |
| `P0-1 合并值 = 各作用域逐日求和（精确校验）` | 同上：合并是后端聚合，前端不持有原始逐日数组 |
| `F2 资源包名不重复` / `F3 目录名与会话名不同批字符串` | 断言的是原型 `SCOPES[].packs` / `SESSION_SEEDS` 演示数据；真实资源包/会话名来自后端，**前端无去重职责** |
| `.proto-note` 样式 / oklch 头像亮度 / `data-act` 命名 | 原型专属 CSS/DOM 契约。真实代码用 shadcn + Tailwind（`bg-emerald-100` 等），**不照搬选择器与色值判据** |
| `P0-5` / `P1-7` / `P1-8` | 同上（纯原型视觉契约） |

### 4.3 与真实语义**相反**、必须显式确认的

| 原型行为 | 真实代码的**有意选择** | 处置 |
|:---|:---|:---|

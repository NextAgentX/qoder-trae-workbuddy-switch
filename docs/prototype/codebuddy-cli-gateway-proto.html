CodeBuddy CLI 接入方式设计稿 · 待拍板

issue #109。后端已就绪（PR #116），只差 UI 落点。

本质 这不是「再挂一个功能入口」，而是 一个二选一开关 —— CLI 的凭据只有一份 （~/.codebuddy/settings.json），两条路都要写它。
两条路 直连上游：本工具写上游 token，选号由本工具的轮换决定； 走本机网关：本工具写网关 Key，选号由网关按模型决定。
混用 CLI 把上游 token 发到本机网关 ⇒ 401；轮换每轮又重写一次 ⇒ 时好时坏， 症状正像「API 密钥无效」。

待拍板 1（主）：这块 UI 放哪儿？下面三个方案，我推荐 A · 设置页新区块。

待拍板 2：切换确认框里要不要把「会清掉上游 token、会关掉自动轮换」逐条列出来（我倾向列）。

待拍板 3：模型下拉要不要给「留空 = 由 CLI 自己决定」这一项（我倾向给，且默认它）。

01

落点三选一

评审第一个问题永远是「这块挂在哪」，所以先答它。

设置

推荐
A · 设置页新增「CodeBuddy CLI」区块
  • 它是**全局一次性配置**，与「外观 / 检测路径 / 数据目录」同类
  • 设置页已有 section 骨架，加一块不动现有版式
  • 离「账号卡上的 CLI 按钮」远一点 —— 那正是要避免的误触
  • 用户要主动找；靠账号卡的 CLI 按钮给一条「去设置」的指路

API 服务

次选
B · 网关页顶部一张「CLI 接入」卡
  • 「走网关」的语境就在这一页，因果最近
  • 能顺手展示「本页这把 Key 就是给 CLI 用的」
  • 网关页已经很满（Key 台账 + 模型 + 账号池），再加一块挤
  • **直连上游**这个选项放在网关页上，语义别扭

账号页

不推荐
C · 账号页顶部横幅
  • 最显眼，一眼看到
  • 账号页是**每账号一行**的语境，全局开关放这里会被读成「这个账号的事」
  • 账号卡的 cliControl 就在旁边，两个入口抢同一件事

03

切换确认框（待拍板 2）

动的是用户级配置文件，必须逐条说清代价。
切到「走本机网关」？
会改写 ~/.codebuddy/settings.json：
  • 写入网关地址 http://127.0.0.1:57891 与一把新 Key
  • 清掉现有的上游 token 与 apiKeyHelper
  • 关闭自动轮换（选号改由网关负责）
改完需要重启终端与 CLI 才生效。

为什么值得单独一拍：「清掉上游 token」是不可见的破坏性操作。

用户的 token 是导入进来的，被清掉后如果想切回直连，需要重新接入一次（不需要重新登录 —— token 仍在账号库里，只是不再写进 settings）。确认框里说清这一点，能省掉一次「我的号怎么没了」的报障。

备选（更轻）：不弹确认框，改在卡片里做「切换前 → 切换后」的两行对照。 代价是用户更容易误点。我倾向弹框 —— 这是低频、高影响的操作。
04

模型下拉（待拍板 3）

CLI 支持 CODEBUDDY_MODEL；留空 = 由 CLI 自己决定。
默认模型
可选
留空 · 由 CLI 自己决定
CLI 用内置默认模型；网关按请求里的模型名路由
固定为某个模型
写入 CODEBUDDY_MODEL，CLI 每次都用它
模型清单来自**当前启用的命名空间**（网关 `/v1/models` 的同一份数据），不另存一份。

为什么默认留空：固定模型会让「网关按模型选号」失去一半意义 —— 用户想换个模型试试时，还得回来改配置。

为什么还是给这一项：有些用户就是想让 CLI 稳定走某个便宜模型（省额度）， 而这个开关本来就存在（CODEBUDDY_MODEL），藏起来反而让人去手改文件。

选定模型后如果该模型在网关侧全部冷却，CLI 会拿到 503 （model_gate_paused）—— 这是正确行为，比静默换模型可预期。

账号卡上的 cliControl 怎么办

网关模式下它不该再能点 —— 否则用户以为能切号。
user_8f3a2c
主力号 · 1,240 积分
切到 CLI 详情
置灰 + 一句解释（hover 或点开）：
「CLI 已走本机网关，选号由网关按模型决定。要按账号切换，请先切回直连上游。」

这一条容易被漏掉：网关模式下「切到 CLI」这个按钮语义上已经不存在了。

后端会直接拒绝（PR #114 的护栏），但让用户点了才看到报错是下策 —— 界面应该先说话。

为什么不干脆隐藏：隐藏会让「CLI 集成」这个能力凭空消失，用户会以为功能被删了。 置灰 + 说明能表达「它还在，只是现在轮不到它」。
06

与后端的对应（已实现）

PR #116 已合入后端；UI 只需调这一个命令。
UI 动作命令 / 返回
一键切到网关 codebuddy_cli_enable_gateway({ region?, model? })
返回 { ok, baseUrl, keyPrefix, key(masked), rotateDisabled, detail }
读当前状态 get_codebuddy_cli_status() → 新增 gatewayMode （非 null = 已走网关，值就是命中的 URL）
切回直连 调 install_codebuddy_cli_helper()（会重写 token）； 需要先清掉网关配置 —— 这一半还没做，见下
拍板后要补的一小块：「切回直连」需要一个新的 codebuddy_cli_disable_gateway（删掉三个网关 env + 恢复 helper）。 现在 install_helper 会被 PR #114 的护栏拦住（这正是它的职责）， 所以「回直连」这条路目前是**断的** —— 必须在做 UI 的同一次补齐。

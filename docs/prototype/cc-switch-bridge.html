配置写入

备份策略写入前把每个目标文件复制为 *.bak.20261109，同名只留最近 3 份。
写入前 diff 预览关闭后「应用档案」会直接写入，不再弹差异确认——快，但看不到会改哪些键。
写入失败时回滚逐文件结果里有任何一个失败，就把本次已成功的文件恢复原状，不留半成品配置。

所有权保护

sentinel

本产品写进客户端配置的每个值都带一枚 sentinel（一个极短的所有权标记）。读到 base URL 指向本地端口但没有 sentinel 时，就判定为「被外部占用」——另一个工具正在用这个端口，我们不覆盖它。

这就是 Claude Desktop 那张卡为什么只给「查看指引」：强行改写会把另一个正在运行的代理打断，属于用户环境破坏。
发现外部占用时影响所有客户端的默认行为，可在单卡上单独覆盖。

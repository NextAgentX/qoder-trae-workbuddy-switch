# Issue #198：CodeBuddy 长期记忆未随账号迁移

> 状态：只读历史（不再更新） · 原始记录日期 2026-11-10

> 用户报障（2026-11-10）：切换账号后「对话、项目、记忆都没跟过来」。排查确认会话复制
> 管线工作正常（三件套齐全），**真正的缺口在记忆**：迁移目标瞄错了文件 ——
> 合并的是客户端的「用户记忆档案」`memory/{uid}_memory.md`（多为空壳模板），
> 而 buddy 智能体实际在用的长期记忆在 `user-{uid}-personal\MEMORY.md`，切换不迁移。
> 涉及 `crates/buddy-switch-core/src/modules/migrate.rs`、`memory.rs`。

## 1. 现象

- 切换后侧边栏会话/空间齐全，但 buddy 的长期记忆是旧账号 9 月的旧内容，
  源账号 11 月积累的记忆（用户明确指定的偏好）全部丢失。
- 若用户执行过「数据迁移」，报告形如 `appended=0, skippedDuplicate=0, changed=false`
  —— **看起来成功，实际什么都没迁**。

## 2. 根因

`memory.rs` 的合并对象是：

```
%USERPROFILE%\.workbuddy\memory\{uid}_memory.md
```

而当前客户端版本（5.9.x 实测）里，这个文件**大多数账号只是空壳模板**：

```markdown
# User Memory Profile
> Last updated: ...
> Version: 0
## Memory Block
---
<!-- RAW_JSON_START { "uid": "...", "memoryBlock": "", "updatedAt": "..." } RAW_JSON_END -->
```

真正的 buddy 智能体长期记忆在**另一个位置**：

```
%USERPROFILE%\.workbuddy\user-{uid}-personal\MEMORY.md
```

（同目录还有 `BOOTSTRAP.md` / `IDENTITY.md` / `SOUL.md` / `USER.md` 一套个人工作区文件，
其中只有 `MEMORY.md` 承载用户积累的记忆；`USER.md` 实测两边都是空模板，无需迁移。）

合并空壳源 = `merge_memory_text` 解析出 0 条有效行 → `appended=0` → 假成功。
这与 2026-11-02 跨版本迁移时的观察一致（当时 6 个账号的 `{uid}_memory.md` 全是空壳）。

## 3. 实测证据（2026-11-10，脱敏）

| 核验项 | 结果 |
|:--|:--|
| 源账号 A `memory\{A}_memory.md` | 254 字节，`memoryBlock: ""`（空壳） |
| 源账号 A `user-A-personal\MEMORY.md` | **1,095 字节，2026-11-08 更新**，含用户明确指定的 SSH 板端连接偏好 |
| 目标账号 B `memory\{B}_memory.md` | 4,389 字节（旧格式，9 月内容） |
| 目标账号 B `user-B-personal\MEMORY.md` | 1,012 字节，**停留在 2026-09-11** |
| 切换（11-09 17:14）后的迁移动作 | 无任何合并发生，也无提示 |

## 4. 建议修法

`migrate_account_data_cross`（`migrate.rs`）增加一个范围：

- 源：`user-{source_uid}-personal\MEMORY.md` → 目标：`user-{target_uid}-personal\MEMORY.md`
- 合并语义沿用 `memory.rs` 的 `merge_memory_text`（追加 + 行级去重）；两份都是纯
  markdown，**不涉及** RAW_JSON 解析，比现状更简单。
- 源文件缺失 ⇒ 跳过；源为空壳（`memory/{uid}_memory.md` 无有效行）⇒ 报告里如实给
  `skipped` + 原因，不要再报 `appended=0` 的假成功。
- `{uid}_memory.md` 的现有合并保留（老客户端仍可能用），但报告里与 personal 记忆
  分开列项。
- 目标改写前走既有 `backup_target_memory` 同款备份。

## 5. 验收标准

- [ ] 迁移后目标账号 `user-{uid}-personal\MEMORY.md` 包含源账号全部非重复行（用例断言）
- [ ] 二次执行幂等：不产生新增行
- [ ] 源为空壳/缺失时，报告该项为 skipped（带原因），不冒充成功
- [ ] 源与目标相同（同 region 同 uid）仍拒绝
